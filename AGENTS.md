# AGENTS.md — tube

Règles universelles pour tout agent IA ou contributeur touchant ce repo.

## Source de vérité agentique

Le guide agentique canonique de ce repo est **`.github/copilot-instructions.md`**
(développement de package R : one-feature-one-branch, une conversation par
feature, conventions de branching séquentielle, etc.). **Lis et suis ce fichier.**

Le présent `AGENTS.md` est un pointeur mince : il ne duplique pas le contenu du
guide — toute duplication diverge. En cas d'écart entre ce fichier et
`.github/copilot-instructions.md`, ce dernier prime pour le détail opérationnel.

## Gitflow

Branche par défaut : `main`. Une feature = une branche, branchée séquentiellement
depuis l'état courant commité/poussé (voir le protocole détaillé dans
`.github/copilot-instructions.md`).
